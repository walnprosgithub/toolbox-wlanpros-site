Toolbox on WLAN Pi

The WLAN Pros Toolbox, served by your own WLAN Pi, reading your own radios.

Not announced yet. This page is live so it can be checked, and is deliberately unlisted. The download is not here because the published installer is out of date and pointing you at it would hand you an old app.

Why this edition exists

Every other edition of the Toolbox runs on a device that holds the operating system at arm’s length. A phone will not decode a DHCP packet for you. A sandboxed Mac will not either. The WLAN Pi is Linux, it is yours, and it says yes.

So this is the edition with no wired ceiling. It reads the full DHCP option list rather than the handful of fields a phone will surrender, and it is the only place a real DORA exchange belongs. It scans with the Pi’s own radios instead of asking the operating system what it feels like sharing, and on a multi-radio Pi it lets you pick which one.

That makes it the reference platform rather than the afterthought. When an edition on another platform cannot answer a question, this is the build that shows you what the honest answer would have been.

What it runs on

Verified on a WLAN Pi R4 running WLAN Pi OS 3.4.4. Other models and OS versions are likely fine and are not yet confirmed, which is a different statement from "supported".

The Pi serves the Toolbox over HTTP on port 8080 and answers 27 endpoints behind it. You reach it from any browser on the same network. Nothing is installed on the machine you browse from.

Read this before you put one on a network you do not own.

A normal install ships plain HTTP with authentication off. That is the right default for a bench tool on your own bench, and the wrong one anywhere else: anyone who can reach the Pi can reach everything it exposes, including tools that send arbitrary packets and wake machines on the LAN.

There is a hardened image-build mode that turns on TLS and HTTP authentication, forces key-only SSH, and regenerates secrets on first boot. If the Pi is going anywhere near a client site, use that one.
